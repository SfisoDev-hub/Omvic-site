# Construction & Maintenance Website

A modern, responsive website for a South African construction and maintenance company, showcasing building, plumbing, electrical, roofing, tiling, paving, renovations, and general maintenance services.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Features

- Responsive design
- Services showcase
- Project portfolio
- Contact form
- WhatsApp integration
- Mobile navigation
- SEO-ready structure

## Getting Started

### Install Dependencies

```bash
npm install

--- Start the Development Server

npm run dev

--- Build for Production

npm run build

Configuration
Company details: src/data/siteConfig.ts
Website images: src/data/images.ts
Portfolio projects: src/data/projects.ts
